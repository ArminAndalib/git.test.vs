## 🎯 About Me

I'm **Armin Andalib**, a Computer Engineering student focused on **cybersecurity**, especially **Red Team operations, web application security, Linux, networking, and security automation**.

I prefer learning through practical labs: understand the architecture, reproduce the vulnerability in a controlled environment, analyze the root cause, then document the mitigation.

> **Security is not a collection of tools. It's a way of thinking.**
